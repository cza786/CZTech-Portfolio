# CZTech-Portfolio

High-performance, modern portfolio and agency website for **CZTech Software & AI Agency**, founded by **Chand Zaib**.

## Tech Stack
- **Framework**: Astro 4
- **Styling**: Tailwind CSS
- **Features**: Responsive Hero, Cutout Portrait & Ambient Aura, Looping Brand Logos Marquee, Smooth Scrolling Services & Portfolio Sections
